# Lecture notes: basic C++ programming

Short C++ examples for beginners, one topic per file. Most files have comments that explain the code.

Topics: input and output, variable types and conversions, loops, `switch`, `break` and `continue`, functions, recursion, arrays, multidimensional arrays, pointers, dynamic memory, strings, bitwise operators, command line arguments. A few files are small games (dice, strings) to practise the basics.

## Run an example

```bash
g++ -std=c++17 hello_world.cpp -o hello_world
./hello_world
```

Related book (in Turkish): *Başlangıç Düzeyinde C++ Öğrenimine Giriş*, S. E. Seker and R. Yoruk, Bilkav, 2018.
